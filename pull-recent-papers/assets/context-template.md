# Reader context for pull-recent-papers

Free-form Markdown; every section is optional. The digest uses this to order
and frame papers, never to drop them.

## Background

Role, field, and the areas you already know well.

## Interests

Topics and problems you want connections flagged for.

## Current work

Projects in progress, and nearby group or collaborator lines.

## Resources

Hardware, testbeds, datasets, or systems you can build on.
