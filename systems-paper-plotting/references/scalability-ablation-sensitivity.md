# Scalability Ablation Sensitivity

## Scalability

Plot actual values against the scaling axis. Add speedup, efficiency, or ideal lines only when the reference point is clear.

Name the scaling axis: threads, cores, nodes, clients, concurrency, data size, or workload size.

## Ablation

Use the full system as baseline. Change one clear component or mechanism at a time.

If multiple factors change together, call it a configuration comparison rather than ablation.

## Sensitivity

Use line plots for ordered parameters such as cache size, threshold, or skew factor. Use dot plots or bars for unordered configurations.

Show the default setting when it matters for interpretation.
